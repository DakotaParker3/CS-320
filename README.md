# CS-320

## How can I ensure that my code, program, or software is functional and secure?
I can ensure my code is functional and secure through performing tests early and often, such as with unit tests throughout this course, to ensure each requirement is fulfilled with funcitional code and error handling is implemented properly.

## How do I interpret user needs and incorporate them into a program?
I convert elicited user needs into user stories in the form of a sentence, such as "As a (type of user), I want to (perform a task) so that I can (achieve a goal)." This helps break down the needs of the user into actionable tasks that can then be incorporated into a program. 

## How do I approach designing software?
I approach designing software by first understanding what is required of that software, such as interpreting user needs, and then creaing a plan through the use of pseudocode or flowcharts to guide development. Continuously testing the software as I develop it, such as through unit testing in this course, and code reviewing help ensure what I write will satisfy the software's requirements. Focusing my approach on the requirements of the software ensures they are met, and limits time spent on anything unnecessary.
